# Git Learning Repository

This repository was created to practice and learn Git fundamentals through hands-on exercises.

## Branches

- `main` - Base branch with initial setup
- `release` - Branch for release preparation (currently active)
- `feat/awesome1` - Feature branch adding "4.txt a1"
- `feat/awesome2` - Feature branch adding "4.txt a2"
- `feat/login` - Feature branch working on 3.txt
- `fix` - Fix branch that was merged into main

## Exercises Completed

1. Initial commit structure (1.txt through 5.txt)
2. Branch creation and switching
3. Merge conflict resolution
4. Feature development on multiple branches
5. Merge branch integration

Each text file (1.txt-5.txt) represents a different exercise step in learning Git operations.
